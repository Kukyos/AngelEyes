# Angel's Eye

CCTV that understands what people are doing — built for women's and children's safety.

HackNex 2026 · HNX26PSI07 — Autonomous Vision & Behaviour Understanding.

> **Status: planning complete, build not started.** Start with [`docs/STATE.md`](docs/STATE.md).

Angel's Eye tracks every person in a camera feed anonymously and flags the moments that
matter — a silent Signal-for-Help hand sign, someone following someone, loitering, a
fall, a sudden run — each with **who**, **when** and the **evidence**. The same data
powers a live 3D map of campus, a clothing-based search for a missing child across
cameras, and walking routes that avoid deserted streets.

No face recognition. No gender inference. Faces blurred everywhere.
